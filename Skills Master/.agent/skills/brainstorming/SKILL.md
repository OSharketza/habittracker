# Brainstorming Enhancements

Use this skill to facilitate creative thinking and structured planning for project growth.

## When to use this skill
- Starting a new feature phase
- Discussing ways to improve user engagement
- Looking for technical solutions to complex user problems
- Prioritizing upcoming development tasks

## Workflow

1.  **Divergent Thinking (Quantity)**: Generate as many ideas as possible without judgment.
2.  **Convergent Thinking (Quality)**: Group, filter, and prioritize the best ideas.
3.  **Identify Goals**: Define the core problem (e.g., "increase retention," "simplify logging").
4.  **Categorize Ideas**: Group suggestions into logic areas (e.g., Logic, UI/UX, Automation).
5.  **Impact vs Effort Assessment**: Use the `Priority Framework` resource to evaluate.
6.  **Select Priority**: Choose the top 1-3 items to proceed with.

## Generic Ideation Categories

### 1. Automation & AI
- Offloading manual tasks to background processes.
- Using LLMs for summarization, advice, or content generation.
- Smart triggers based on user behavior or external events.

### 2. User Experience (UX) & Flow
- Reducing "clicks to action" in critical workflows.
- Batch operations for repetitive tasks.
- Navigation improvements (Quick Actions, Command Palettes).

### 3. Engagement & Retention (Gamification)
- Progression systems (XP, Levels, Progress bars).
- Reward loops (Badges, Streaks, Notifications).
- Social or collaborative features.

### 4. Data & Observability
- Interactive visualizations for insights.
- Correlation analysis (e.g., "Feature A vs. Metric B").
- Real-time feedback and status dashboards.

## Best Practices
- **No Bad Ideas**: Capture everything first, filter later.
- **User-Centric**: Always ask, "How does this actually help the person using the app?"
- **Fail Fast (Low Fidelity)**: Sketch or describe the workflow before writing code.
- **Iterative Growth**: Focus on the "High Impact" but "Medium/Low Effort" items first.
