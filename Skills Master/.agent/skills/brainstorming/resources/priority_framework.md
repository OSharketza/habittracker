# Brainstorming Priority Framework

Use this framework to decide which ideas to implement first.

## 1. Impact vs. Effort Matrix

| Impact / Effort | Low Effort | High Effort |
| :--- | :--- | :--- |
| **High Impact** | **Top Priority (Quick Wins)** | **Strategic Projects** |
| **Low Impact** | **Fillers / Polishing** | **Discard / Defer** |

## 2. Decision Criteria
- **User Value**: Does this solve a burning pain point?
- **Uniqueness**: Is this a "killer feature" that differentiates the app?
- **Prerequisites**: Does this require other features to be built first?
- **Maintenance**: Will this be hard to keep up-to-date?
